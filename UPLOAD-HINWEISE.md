# GitHub Upload-Hinweise

1. Lade den Inhalt **dieses Ordners** (nicht den übergeordneten Ordner) in das öffentliche Repository `Marziipa/TVLoungeJS` hoch.
2. Bestehende Dateien `index.html`, `styles.css` und `README.md` ersetzen; `assets/` mitsamt Unterordner hochladen.
3. `.nojekyll`, `privacy.html`, `privacy-ko.html` und `qa-test-playlist.m3u` unverändert beibehalten.
4. GitHub Pages prüfen: Einstellungen → Pages → Deploy from a branch → `main` / root (falls noch nicht aktiv).
5. Links, Screenshots, Mobilansicht und Datenschutzseiten nach Veröffentlichung kontrollieren.
6. Nach dem Store-Release den Coming-Soon-Status und Download-Link aktualisieren.

**Hinweis:** Das Paket verwendet nur freigegebene Screenshots und ein öffentliches App-Icon aus dem gelieferten Tizen-ZIP. Prüfe dennoch die Bildrechte vor der Veröffentlichung. Keine privaten Source-Dateien wurden übernommen.

Für einen besonders risikoarmen Upload zuerst einen eigenen Git-Branch erstellen und die Änderungen per Pull Request überprüfen.
